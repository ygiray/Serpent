**What went well**

- Communication in the team worked well; members helped each other (reviews, setup problems).
- Every SRS/SDD section had a clear owner, and the shared naming conventions kept the ER diagram, API list and sequence diagrams consistent.

**What went wrong**

- Most parts were delivered on the last day; the internal deadline (Saturday 20:00) was partly missed.
- One commit was pushed directly to `main` without a pull request (SCRUM-80); it was reviewed afterwards.
- One branch was created without a Jira key (`ilkerbdev-patch-1`).
- Some Jira tasks were not moved to "In Progress" when the work started.

**Findings from the local setup (Node.js 22)**

- On Windows, `npm install` in `server/` fails with `gyp ERR!` because `better-sqlite3` is compiled locally. It needs Python 3 and Visual Studio Build Tools (C++).
- PowerShell may block `npm` ("running scripts is disabled"); fix: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.
- `npm audit fix --force` must not be run (it changes major versions and `package-lock.json`).
